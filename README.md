# LVGP Race Week Guide

A phone-friendly guide to Las Vegas Grand Prix 2026 race week (Nov 18 to 22): team fan zones, driver appearances, pop-ups, a Strip map, the F1 and F1 Academy schedule, the monorail, and vegetarian food.

It is one static file, `index.html`, with no build step. To-do items and calendar picks are saved in each visitor's browser only.

## Deploy on Vercel

1. On vercel.com, choose **Add New → Project** and import this repository.
2. Leave Framework Preset as **Other**, with no build command and no output directory.
3. Click **Deploy**. Every push to `main` redeploys automatically.

Event details were checked on Nov 17, 2026. Times can change, so check the source links on each card.
